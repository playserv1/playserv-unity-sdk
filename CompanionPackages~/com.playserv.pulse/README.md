# PlayServ Pulse

Optional realtime configuration and feature flag surface for
`com.playserv.sdk`.

Pulse is intentionally disabled by default while its backend contract is still
being developed. Installing the package makes the module available in the main
PlayServ SDK module settings, where it can be enabled independently.

For Git installations, use the same tag or commit as the core SDK:

```json
"com.playserv.pulse": "git@github.com:playserv1/playserv-unity-sdk.git?path=/CompanionPackages~/com.playserv.pulse#<tag-or-commit>"
```
